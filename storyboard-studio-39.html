🎞️ FRAME-TO-FRAME / SHOT BREAKDOWN GUIDE

    
    

      

        
        
      

    

    
Ye guide purane prompt (20-Blocks, Character DNA, Atmosphere / Night lock, Calm lock, HUD) ko bilkul nahi chhedta — wo jaisa tha waisa rehta hai; sirf uske neeche ek alag "FRAME-TO-FRAME SHOT BREAKDOWN" block add hota hai. Frames scene ke action text se khud (offline, bina API call ke) banate hain: Frame 1 = Shuruaat, aakhri frames = Impact aur Reaction. Har frame pichle frame ke aakhri pose/position/camera se shuru hota hai (koi teleport ya jump nahi), aur har scene ka Visual Bridge pehle frame ko pichle scene se jodta hai. Har scene card mein "🎞️ Frame-to-Frame breakdown" se us scene ke frames dekh sakte hain, count badal sakte hain, ya "✨ AI se refine" se behtar frames likhwa sakte hain. Slideshow (static image) mode mein ye guide band rehta hai kyunke wahan har scene ek hi image hai.
